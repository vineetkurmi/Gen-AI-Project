Artificial Intelligence (AI) enables computers to perform tasks that normally require human intelligence. Machine Learning is a subset of AI that allows systems to learn from data and improve their performance over time.

Retrieval-Augmented Generation (RAG) combines document retrieval with large language models. A RAG system searches relevant documents, retrieves useful information, and uses that information to answer user questions.

FAISS is a vector database library used to store and search text embeddings efficiently. It helps retrieve the most relevant document chunks for a given query.
